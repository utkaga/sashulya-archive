# Сайт Шурика — восстановленная копия

Семейный сайт, созданный на Jimdo в 2009 году и восстановленный по материалам Web Archive.

## [Открыть сайт на GitHub Pages](https://utkaga.github.io/sashulya-archive/)

Резервная рабочая версия: [sashulya-archive.utkaga.chatgpt.site](https://sashulya-archive.utkaga.chatgpt.site/)

В восстановленную версию перенесены:

- 19 архивных страниц;
- основные разделы и 12 фотоисторий;
- сохранившиеся семейные фотографии;
- тексты, даты, подписи и архивные видео;
- оформление сайта образца 2009–2013 годов.

В исходном HTML обнаружены ссылки на сотни изображений Jimdo. Часть файлов не была сохранена веб-архивом, поэтому на соответствующих страницах оставлены восстановленные тексты и сведения о количестве утраченных фотографий.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npx vinext build
node --test tests/rendered-html.test.mjs
```
